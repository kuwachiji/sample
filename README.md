# 地図にピンを刺してみよう（Leaflet.js サンプル）

緯度・経度を指定して、地図上にピン（マーカー）を立てる練習用のサンプルです。
プログラミングが初めての人でも動かせるように、1つのファイルだけで完結しています。

教材（緯度経度のしくみ・課題・参考サイト）は [TEXTBOOK.md](TEXTBOOK.md) にあります。

## ファイルを手に入れる

### git を使わない場合（おすすめ・アカウント不要）

GitHub のこのページから ZIP でまるごとダウンロードできます。

1. ファイル一覧の左上にあるブランチ名のボタン（`main` と書いてあるところ）を押して、
   **ほしいブランチを選ぶ**
2. 右上の緑の **Code** ボタンを押す
3. 出てきたメニューの **Download ZIP** を押す
4. ダウンロードされた ZIP を解凍（ダブルクリック）する

解凍してできたフォルダの中の `index.html` をダブルクリックすれば、そのまま動きます。

`index.html` 1つだけあれば動くので、GitHub でそのファイルを開いて **Raw** ボタンを押し、
右クリック →「別名で保存」でもかまいません。

> このリポジトリが **Private** の間は、ダウンロードにも GitHub へのログインと権限が必要です。
> 授業などで配るときは、Public にするか、先に ZIP を作って別の方法（共有ドライブなど）で
> 渡してください。

### git が使える場合

```bash
git clone https://github.com/kuwachiji/sample.git
cd sample
```

## 使いかた

1. `index.html` をダブルクリックしてブラウザで開く
2. 東京駅あたりの地図と、3本のピンが表示されます
3. 下の入力欄に緯度・経度を入れて「ピンを刺す」を押すと、その場所にピンが増えます

インストールや準備は不要ですが、**インターネットにつながっている必要があります**
（地図の絵と Leaflet をネットから読み込むため）。

## 緯度・経度の調べかた

- [Google マップ](https://www.google.com/maps) で場所を右クリックすると、
  `35.658581, 139.745433` のような数字が出ます。前が緯度、後ろが経度です。
- 日本はだいたい 緯度 24〜46 / 経度 123〜146 の範囲です。

試してみる例：

| 場所 | 緯度 | 経度 |
| --- | --- | --- |
| 東京タワー | 35.658581 | 139.745433 |
| 大阪城 | 34.687315 | 135.526201 |
| 札幌時計台 | 43.062660 | 141.353539 |

## コードを書きかえてみる

`index.html` をテキストエディタで開いて、`const pins = [` の部分を探してください。

```js
const pins = [
  { name: "東京駅", lat: 35.681236, lng: 139.767125 },
  ...
];
```

`name` が名前、`lat` が緯度（latitude）、`lng` が経度（longitude）です。

この行をまねして増やしたり、数字を変えたりすると、最初から出るピンが変わります。
書きかえたら保存して、ブラウザを再読み込み（リロード）してください。

## つまずいたときは

- **地図が真っ白**: CSS の `#map { height: 60vh; }` を消していませんか？
  地図を入れる箱には高さの指定が必要です。
- **ピンが出ない**: 緯度と経度を逆に入れていないか確認してみてください。
- **地図の絵が出ない**: インターネットにつながっているか確認してください。
- **Safari で開くと「Unsafe attempt to load URL」と出る**: Safari はパソコン内のファイルを
  直接開くのを制限しています。Chrome や Edge で開いてください。
  どうしても Safari で見たいときは、`index.html` のあるフォルダで下のコマンドを実行してから
  <http://localhost:8000/index.html> を開きます（Mac なら最初から使えます）。

  ```bash
  python3 -m http.server 8000
  ```
